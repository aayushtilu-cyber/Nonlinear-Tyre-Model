# Tire Tread Simulation Model

## Overview

A custom nonlinear tire tread simulation model developed in MATLAB for vehicle dynamics applications.

The model predicts tire forces and moments by simulating contact patch behavior using a distributed tread approach with adhesion and sliding regions. The model incorporates combined-slip effects and can be used for vehicle dynamics simulations, lap time simulation, and tire force analysis.

---

## Features

- Lateral Force (Fy) Prediction
- Longitudinal Force (Fx) Prediction
- Aligning Torque (Mz) Calculation
- Combined Slip Modelling
- Friction Circle Generation
- Camber Angle Effects
- Contact Patch Based Tread Simulation

---

## Applications

- Formula Student Vehicle Development
- Vehicle Dynamics Analysis
- Lap Time Simulation
- Tire Force Characterization
- Performance Simulation

---

## Model Parameters

| Parameter | Value |
|-----------|---------|
| Vertical Load (Fz) | 3000 N |
| Contact Length (2a) | 0.20 m |
| Contact Width (2b) | 0.16 m |
| Rolling Radius | 0.30 m |
| Friction Coefficient | 1.0 |
