# Tire Tread Simulation Model

## Overview

A custom nonlinear tire tread simulation model developed in MATLAB for vehicle dynamics applications.

The model predicts tire forces and moments by simulating the contact patch behavior using a distributed tread approach with adhesion and sliding regions.

---

## Features

- Lateral Force (Fy) Prediction
- Longitudinal Force (Fx) Prediction
- Aligning Torque (Mz) Calculation
- Combined Slip Modelling
- Camber Effects
- Pressure Distribution Analysis
- Friction Ellipse Generation

---

## Applications

- Formula Student
- Vehicle Dynamics
- Lap Time Simulation
- Performance Analysis

---

## Model Parameters

| Parameter | Value |
|-----------|---------|
| Fz | 840 N |
| Contact Length (2a) | 0.20 m |
| Contact Width (2b) | 0.16 m |
| Rolling Radius | 0.30 m |
| Friction Coefficient | 1.0 |
